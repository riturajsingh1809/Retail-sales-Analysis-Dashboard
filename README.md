# Retail Sales Analysis Dashboard

## Developed by Ritu Raj Singh

---

## 📊 Project Overview

This project presents an interactive and professional *Retail Sales Analysis Dashboard* developed using *Tableau*.

The dashboard provides a clear overview of transaction performance through KPI cards, charts, and interactive filters. It helps users understand sales amount, transaction records, transaction status, city-wise performance, source-system performance, and sales trends.

---

## 🎯 Project Objectives

- Analyze overall transaction and sales performance
- Track important business KPIs
- Compare completed and pending transaction amounts
- Analyze transaction status
- Identify city-wise performance
- Compare performance across different source systems
- Monitor sales trends over time
- Present insights through an interactive Tableau dashboard

---

## 📈 Key Performance Indicators

The Tableau dashboard includes important KPI metrics such as:

- *Total Amount*
- *Total Records*
- *Completed Amount*
- *Pending Amount*

These KPIs provide a quick overview of overall transaction performance.

---

## 📊 Dashboard Analysis

The dashboard provides analysis through the following views:

### 1. KPI Overview
Provides a high-level view of total amount, total records, completed amount, and pending amount.

### 2. Status Analysis
Shows transaction performance across different statuses.

### 3. City Performance
Compares transaction amounts across different cities.

### 4. Source System Analysis
Analyzes transaction amounts by source system.

### 5. Monthly Amount Trend
Shows how transaction amount changes over time.

### 6. Status Distribution
Provides a comparison of transaction counts across different statuses.

## 🔍 Key Insights

The dashboard helps identify:

- Overall transaction and sales performance
- Completed versus pending transaction amounts
- Cities contributing higher transaction amounts
- Source systems generating higher transaction activity
- Changes in transaction amounts over time
- Distribution of transactions across different statuses
